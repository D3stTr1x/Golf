# Golf

## Идея

### Первоначальный этап
Адаптация ТЗ под игру гольф. Главный герой - имеющийся персонаж с мотыгой. 
Игра должна быть конечна. Меню начало, Финальный экран(победа, поражение).
Геймплей - игрок может ходить между локациями(полями). 
Победа - набрано определённое количество очков (победить босса).
